Shadow Levels

The signature shadow-as-border technique replaces traditional CSS borders with box-shadow rings. Each level adds purpose-built layers for dimensional depth.

Level 0 - FlatNo shadow. Page background.
Level 1 - RingShadow-as-border. The signature.
Level 1b - Light RingLighter ring for tabs and images.
Level 2 - Subtle CardRing + minimal lift for cards.
Level 3 - Full CardRing + elevation + ambient + inner glow.
Focus RingAccessibility focus on all interactive elements.
