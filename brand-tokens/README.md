## Usage

Brand tokens serve as **reference libraries** for the tasteful-frontend design spec generator. They provide real-world aesthetic knowledge that informs Tier 3 aesthetic directives.

When generating a new design spec with a specific aesthetic direction:
1. The generator can reference a brand token file for inspiration
2. Required tokens from `spec-schema.yaml` must still be present
3. Extended brand tokens (accent-secondary, neutral scales, etc.) are optional enrichment

## Format

All files follow W3C DTCG v2025.10 with `$extensions` metadata:
```json
{
  "$extensions": {
    "brand": "claude",
    "source": "awesome-design-md",
    "aesthetic": "literary salon on parchment",
    "key-characteristics": ["warm-editorial", "serif-driven", "parchment-canvas"]
  },
  "color": { ... },
  "typography": { ... }
}
```
